<product_requirements>
The product is a sophisticated GPT Signal Bot, a full-stack web application designed to generate and execute high-accuracy trading signals for the Pocket Option platform.

**Core Features & User Goals:**
*   **Signal Generation:** The system's primary function is to generate BUY/SELL signals for binary options across multiple timeframes (5s, 15s, 30s, 1m, 3m, 5m). The user's goal is to achieve the highest possible accuracy, targeting 90%+.
*   **Customizable Strategies:** Users must be able to choose from a variety of trading strategies for each timeframe. The application was expanded from a default strategy to a full selection tool featuring over 15 new strategies based on user-provided logic and online research (e.g., Keltner/Fractal, 3-EMA Crossover, RSI/MACD/BB combos, ICT concepts).
*   **Operational Modes:** The bot supports both Auto Generate for continuous signal generation and Force Generate for on-demand signals.
*   **Precise Timing:** A critical requirement is that signals must be perfectly synchronized with Pocket Option's candle formation times. This involves compensating for network and processing latency to ensure signals arrive at the optimal entry point.
*   **Risk Management:** A Money Management Calculator component, based on a user-provided  file with a Martingale-style progression, has been integrated to help users manage trade amounts and risk.
*   **Frontend Dashboard:** A React-based UI provides controls for starting/stopping the bot, selecting assets, choosing strategies, viewing live signals, and using the money management tool.
