<product_requirements>
The goal is to build an autonomous GPT Signal Bot for the Pocket Option trading platform, designed to generate sureshot trading signals with a target accuracy of 98% or higher.

The system must operate on **real-time market data**, not simulated data, fetching prices for all assets available on Pocket Option, including Forex, commodities, crypto, and OTC markets. It should perform multi-layered analysis using technical indicators (RSI, MACD, EMA, CCI), LLM-driven sentiment analysis from news and social media, and machine learning for pattern recognition.

The user interface must be a modern, mobile-friendly web dashboard. Key UI features include:
- A live dashboard displaying real-time market prices and performance metrics.
- A comprehensive asset/market and timeframe selection tool (5s to 30m).
- Controls to start/stop the bot, enable/disable popup and sound alerts, and an invert signals button to reverse trade directions (e.g., BUY becomes SELL).
- A live display section for recently generated signals.

Crucially, the bot must integrate with three external platforms:
1.  **Pocket Option:** For fully automated trading, using the user's SSID and credentials to execute trades based on generated signals.
2.  **Telegram:** To push all generated signals to a specified bot (@ElitePocket_bot) and chat ID.
3.  **Autobotsignal.io:** To send signals to a specific WebHook URL in a predefined JSON format.
</product_requirements>
